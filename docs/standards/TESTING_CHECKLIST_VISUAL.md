# Testing Checklist - Visual Updates

## 1. Node Appearance
- [ ] **Event Nodes:** Check Diamond+Arrow icon, Red gradient, Transparency.
- [ ] **SET Nodes:** Check Centered/Italic header, Input Arrow+Circle pins.
- [ ] **GET Nodes:** Check Capsule shape, Gloss overlay, Right-aligned pin.
- [ ] **Transparency:** Verify wires are visible behind nodes.
- [ ] **Selection:** Verify Orange outline on all node types.

## 2. Pin Rendering
- [ ] **Input Pins:** Verify Arrow points right (into circle).
- [ ] **Output Pins:** Verify Arrow points right (out of circle).
- [ ] **Connection State:** Verify pins fill when connected, hollow when empty.
- [ ] **Colors:** Verify correct colors for Bool (Red), Float (Green), Vector (Gold).

## 3. Widgets
- [ ] **Vector/Rotator:** Check X, Y, Z input fields appear in pin row.
- [ ] **Checkbox:** Check Boolean inputs use custom checkbox style.

## 4. Editor Theme
- [ ] **Background:** Check Dark Gray grid.
- [ ] **Panels:** Check Dark sidebars.
