Complete Reference Summary

  • Events: Red gradient, diamond+arrow icon, delegate icon
  • Flow Control: Gray gradient, Font Awesome icons
  • Impure Functions: Blue gradient, FA cube icon
  • Pure Functions: Green gradient, no exec pins
  • SET Nodes: Variable-type color gradient, centered italic
  • GET Nodes: Capsule shape, horizontal layout

  • Exec: White (#FFFFFF)
  • Boolean: Red (#920101)
  • Float: Neon Green (#00EA32)
  • Object: Cyan Blue (#00A8E8)
  • String: Magenta (#FF00FF)
  • Vector: Gold (#FFC700)
  • Rotator: Purple (#9999FF)
