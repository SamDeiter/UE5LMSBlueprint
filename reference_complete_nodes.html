Reference Notes:

  • Event Node: Red gradient header, diamond+arrow icon, hollow red delegate icon
  • SET Node: Variable-type-based header color (blue for Object, green for Float), centered italic title
  • GET Node: Capsule shape, horizontal layout, gloss overlay, no header
  • Pins: All data pins use SVG compound (circle + arrow), exec pins use SVG wedge
  • Colors: Dynamic based on pin type (#00EA32 green for Float, #00A8E8 blue for Object)
